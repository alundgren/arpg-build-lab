# Local generated artifacts

Store raw imports, datasets, checkpoints, and run output here. Contents are
ignored by Git, except this instruction file. Read
`../docs/agents/development.md` for the versioned layout and metadata agreement.

Use small synthetic or permission-checked examples elsewhere when a task needs
a committed fixture. Do not force-add raw saves, bulk datasets, or model files.
Do not delete local artifacts merely because they are ignored; they may contain
work that is expensive or impossible to reproduce.
